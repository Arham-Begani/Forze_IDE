# Icon Placeholders

The Tauri bundler references PNG/ICNS/ICO icons here. Drop them in before the
first `pnpm tauri:build` (use `tauri icon ./logo.svg` to generate from a single
SVG). Names referenced in `tauri.conf.json`:

- `32x32.png`
- `128x128.png`
- `128x128@2x.png`
- `icon.icns`
- `icon.ico`
